While I have a strong foundation and a deep interest in domains like network forensics, VPN architectures (IKE/ESP), and the intersection of AI and security (like AI-driven phishing firewalls), consuming tutorials and lectures is no longer enough.

## 🧭 The "How": My Methodology

For the next 100 days, I am treating this repository as my public lab notebook. I dedicate at least 1 to 1.5 hours daily to focused, hands-on cybersecurity work.

My approach is structured around consistent progression and tangible outputs:

### 1. Hands-On Execution
Instead of just reading about security, I deploy environments, analyze raw data, and write code. My daily focus rotates through core pillars:
* **Network & Traffic Analysis:** Capturing and dissecting packets, studying encapsulation, and understanding how data moves (and hides) on a network.
* **Linux & Command-Line Mastery:** Building muscle memory for rapid navigation, file manipulation, and system administration.
* **Custom Tooling:** Writing Python scripts to automate tasks, from basic port scanners to more complex data obfuscation and steganography tools.
* **Vulnerability Research:** Completing CTFs, engaging with platforms like TryHackMe and OverTheWire, and documenting the exploit chains.

### 2. Meticulous Documentation
*"If it isn't documented, it didn't happen."*  
Every day, I push an update to this repository including:
* **Markdown Write-ups:** Step-by-step methodologies of labs completed, topologies built, or PCAP files analyzed.
* **Code with Context:** Custom scripts uploaded with clear `README.md` files explaining the objective, tools used, and execution instructions.
* **Daily Log:** A running chronological log at the bottom of this master README detailing exactly what was accomplished each day.

### 3. Building in Public
Learning in a vacuum limits growth. I actively distill my daily technical learnings into concise insights and share them with the broader professional community to gather feedback, learn from industry experts, and refine my understanding.
