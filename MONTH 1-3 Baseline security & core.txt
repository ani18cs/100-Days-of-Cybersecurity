PROJECTS
------------------------------------------------------------------------------------------------------------------------------------------------
1.The Multi-Tier Secure Cloud Architecture: 
Deploy a secure network infrastructure inside AWS or Azure. Configure private and public subnets, deploy a virtual firewall, disable all public internet access to databases, and set up strict IAM roles ensuring the Principle of Least Privilege.

2.The Automated Cloud Audit & Compliance Report: 
Deploy a misconfigured infrastructure on a free-tier cloud account (e.g., leaving an S3 storage bucket wide open to the public). Run a free cloud compliance tool like Prowler or AWS Security Hub against your environment. Generate a compliance report detailing which CIS Benchmarks or ISO 27001 controls failed, then write a manual remediation guide fixing those flaws.
